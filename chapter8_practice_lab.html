1

Vim Simulator

Practice Vim's modal editing in this interactive simulator. Remember: Vim starts in Command mode. Press i to enter Insert mode, Esc to return to Command mode.

Quick Reference

Modes
i Insert before cursor
I Insert at start of line
a Append after cursor
A Append at end of line
o Open line below
O Open line above
v Visual (character) select
V Visual line select
Esc Back to Command mode
Moving around
h j k l Left, down, up, right
w Forward one word
b Back one word
e End of word
0 Start of line
^ First non-blank character
$ End of line
gg First line
G Last line
10G Go to line 10
:25 Go to line 25
5j Down five lines — counts work on any motion
Editing
x Delete character under cursor
X Delete character before cursor
r Replace one character
s Substitute character, then insert
S Clear line, then insert
dd Delete line
3dd Delete three lines
dw Delete to next word
de Delete to end of word
db Delete back one word
d$ or D Delete to end of line
d0 Delete to start of line
cw Change word
cc Change whole line
c$ or C Change to end of line
J Join with line below
~ Toggle case of character
u Undo
Copy and paste
yy Yank (copy) line
3yy Yank three lines
yw Yank to next word
y$ Yank to end of line
p Paste after cursor / below line
P Paste before cursor / above line
Visual mode
v then motion Select characters
V then j k Select whole lines
d Delete the selection
y Yank the selection
c Change the selection
Esc Cancel the selection
Search, replace and files
/text Search forward for text
?text Search backward
n Next match
N Previous match
:s/old/new/ Replace first match on this line
:%s/old/new/g Replace every match in the file
:set nu Show line numbers
:set nonu Hide line numbers
:w Write (save)
:wq or :x Write and quit
:q Quit
:q! Quit without saving

2

Nano Simulator

Nano is simpler than Vim — just start typing! There are no modes to worry about. Use Ctrl+key combinations for commands. The shortcuts are always shown at the bottom of the screen.

Quick Reference

Ctrl+O Save file
Ctrl+X Exit
Ctrl+K Cut line
Ctrl+U Paste
Ctrl+W Search
Ctrl+G Help

  • View help with Ctrl+G
